# For You ♡

Template website hadiah digital sederhana dengan suasana senja, karakter yang bisa digerakkan, surat kecil, galeri foto, musik, dan pertanyaan interaktif.

## Cara mengedit
1. Buka file `index.html` untuk mengganti nama, tulisan, dan isi surat.
2. Buka `style.css` untuk mengubah warna, ukuran, dan tampilan.
3. Buka `script.js` untuk mengubah interaksi karakter dan tombol.
4. Unggah foto ke folder `assets` dengan nama `foto-1.jpg`, `foto-2.jpg`, dan `foto-3.jpg`.
5. Unggah musik ke folder `assets` dengan nama `lagu.mp3`.

## Menjalankan website
Buka `index.html` di browser, atau aktifkan GitHub Pages melalui **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Setelah GitHub Pages aktif, situs akan tersedia di:
`https://ariewidianto.github.io/for-you/`
